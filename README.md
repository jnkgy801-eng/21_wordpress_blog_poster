# 大人ナビ（adult-navi21.com）FANZA動画 同期リポジトリ

FANZA動画のランキング・価格・レビューを毎日取得し、WordPress の `/av/` 以下のサイトに送り込みます。
サイトの狙いは「FANZA動画を、**いつ・いくらで・どれを買うか**が分かるナビ」です（価格の記録・急上昇・レビュー件数を加味した「ハズレ回避スコア」）。

```
GitHub Actions ──(DMM API取得 → 年齢フィルター → レビュー下限)──▶ WordPress REST (/wp-json/av/v1) ──▶ 専用テーブル
                                                                                   │
サイト側のPHP（AVハブ）◀────────────────────────────────────────────────────────────┘
  /av/ 新着・人気・急上昇・高評価・最安値・セール・ジャンル/女優/メーカー・作品詳細 …

GitHub Actions ──(サイトの公開データ)──▶ 画像カード作成 ──▶ Bluesky 自動投稿
```

> サイト側のPHP（AVハブ本体、v1.10.0）は `wp/av_hub_mu_plugin.php` にあります。`wp-content/mu-plugins/` に置いて使います（置き換え手順は「8」）。

## 2. 初回セットアップ

### 2-1. WordPress 側
1. 設定 → 一般 → **タイムゾーンを「東京」** にする（日付・ランキングの切り替えが日本時間になる）。
2. 設定 → パーマリンク → 「投稿名」など、`?p=123` 以外を選ぶ。
3. `wp/av_hub_mu_plugin.php` を `wp-content/mu-plugins/` に置く（Code Snippets で動かす場合は中身を貼る）。
4. `https://あなたのドメイン/av/` が表示されることを確認する。
5. ユーザー → プロフィール → **アプリケーションパスワード** を作る（**管理者**ユーザーで作ること）。

### 2-2. GitHub 側
1. このフォルダを新しいリポジトリ（**Private 推奨**）に置く。
2. Settings → Secrets and variables → Actions に、次を登録する。

**Secrets（秘密情報）**

| 名前 | 用途 | 必須 |
|---|---|---|
| `DMM_API_ID` / `DMM_AFFILIATE_ID` | DMM API | 必須 |
| `WP_URL` | 例 `https://adult-navi21.com`（末尾スラッシュなし） | 必須 |
| `WP_USERNAME` / `WP_APP_PASSWORD` | WordPress の管理者ユーザーとアプリケーションパスワード（24文字） | 必須 |
| `BSKY_HANDLE` / `BSKY_APP_PASSWORD` | Bluesky 投稿（アプリパスワードを使う。通常のパスワードは使わない） | 投稿するとき |
| `DISCORD_WEBHOOK_URL` | 同期が失敗したときの通知 | 任意 |

**Variables（秘密でない設定。すべて任意）**

| 名前 | 意味 | 既定 |
|---|---|---|
| `EXTRA_EXCLUDE` | 取り込みから除外する語（カンマ区切りの正規表現）。`age_filter.py` に追加される | なし |
| `FOCUS_KEYWORDS` | `primary` カテゴリ（NTR）の検索語を上書き。`-` にするとそのカテゴリを取得しない | categories.json の値 |
| `RANK_TOP_N` | ランキングとして保存する件数（最大100） | 100 |
| `REFRESH_N` | 価格・レビューを毎日更新する人気上位の件数 | 300 |
| `NEW_DAYS` / `NEW_MAX` | 新着として遡る日数 / 最大件数 | 14 / 300 |
| `FOCUS_N` | 特化カテゴリごとの取り込み件数 | 200 |
| `INDEXNOW_KEY` | 設定すると、同期後に IndexNow で更新を通知する | なし |
| `BSKY_LABEL` | Bluesky の自己申告ラベル（`porn` / `sexual` / `nudity` / `graphic-media`） | porn |
| `BSKY_CATS` | 投稿する対象（`ntr,hard` / `all` / `ending` / `rotate`）。空なら全カテゴリ＋終了間近のセール | 空 |
| `WEEKLY_HASHTAGS` / `ENDING_HASHTAGS` | カテゴリに指定が無いときのタグ / 終了間近の投稿のタグ | `#FANZA #AV` / `#FANZA #セール` |
| `WEEKLY_MASK_WORDS` | 画像内で伏せたい語（カンマ区切り） | なし |

### 2-3. 動作確認は、この順番で
Actions → **AVハブ同期（FANZA → WordPress）** → Run workflow で、`mode` を順に変えて実行します。

| 順 | mode / dry_run | 何を確認するか |
|---|---|---|
| 1 | `check` | WordPress との接続と認証。失敗したら、原因と対処が日本語で表示される |
| 2 | `cats` | `categories.json` の各カテゴリが DMM API から取れるか。レビューが付いている作品数、`min_reviews` を満たす作品数も出る |
| 3 | `daily` + **dry_run = true** | 取得とフィルターだけ（WordPress には送らない） |
| 4 | `backfill` | 初回の大量取り込み（人気順2000件＋直近90日の新着）。**1回だけ** |
| 5 | `daily` | 以降は自動（毎日 05:00 / 17:00 JST）。ランキング推移は毎日たまるので、「急上昇」は**2日目から**表示される |

## 4. カテゴリの設定（`content/categories.json`）

ヘッダーのタブ（NTR / ハード系 / 素人）に対応します。`slug` はサイト側の `AV_HUB_CATS` と同じにしてください。

| キー | 意味 |
|---|---|
| `slug` | URL（`/av/{slug}/`）。英小文字・数字・ハイフンの2〜20字。`new` `rank` `sale` など、サイトの別ページで使われている語は使えない |
| `label` | タブ名・投稿の見出し |
| `floor` | `videoa`（ビデオ）/ `videoc`（素人） |
| `keywords` / `genre_name` / （どちらも無し） | 集め方。キーワード検索 / FANZAのジャンル名（IDは自動で引く）/ フロアの全作品 |
| `add_genre` | 取り込む作品にこのジャンル名を付け足す（サイト側がジャンル名でカテゴリを判定するため） |
| `primary` | 従来の特化ジャンル（NTR）に1つだけ付ける |
| `hashtags` | Bluesky 投稿のタグ |
| `n` / `rank_n` | このカテゴリの取り込み件数 / ランキングとして記録する件数 |
| **`min_reviews`** | **レビュー件数がこれ未満の作品を取り込まない**（0 または省略=制限なし） |
| **`fetch_new`** | `false` にすると新着を集めない（人気順だけ） |
| **`enabled`** | `false` にすると、そのカテゴリの取り込み・ランキング・Bluesky投稿をすべて止める |

### よくある変更

**素人を「名前だけの作品」で埋めない**（現在の設定）
```json
{ "slug": "amateur", "label": "素人", "floor": "videoc", "add_genre": "素人",
  "min_reviews": 3, "fetch_new": false, "hashtags": "#素人" }
```
新着の素人作品はレビューがほぼ0件なので、`min_reviews` を付けるなら `fetch_new: false` も一緒にして、無駄なAPI呼び出しを避けます。
基準は `cats` モードの「`min_reviews` を満たす作品: x/y件」を見て調整してください。**0件になる場合**は、このフロアのAPIにレビューが含まれていない可能性があるので、`min_reviews` を0に戻してください。

**カテゴリを止める**（タブを減らす前にデータ取得を止めたいとき）
```json
{ "slug": "hard", "label": "ハード系", "genre_name": "淫乱・ハード系", "enabled": false }
```
止めても、すでに取り込んだ作品はサイトに残ります。タブを消すには、サイト側の `AV_HUB_CATS` も直してください。

**注意:** このリポジトリ側の `min_reviews` と `enabled` は、これから取り込む作品にだけ効きます。**すでにサイトに入っている**低レビューの素人作品は、PHP側（v1.10.0）の `min_reviews` で、素人タブ・トップ・新着・急上昇・注目から非表示になります（データは残ります）。

## 5. 取り込み前のフィルター

- `age_filter.py` … サイトに取り込む前の判定。現在の基本パターンは `小学` の1語だけで、運用中は GitHub の Variables **`EXTRA_EXCLUDE`**（カンマ区切りの正規表現）で語を足していく前提です。除外された作品はログに `🛡️ 除外:` と出ます。
- `social_filter.py` … Bluesky 投稿用。学校・年齢・幼さを連想させるタイトルは、投稿の画像・文章から外します（サイトの掲載には影響しません）。
- カテゴリの `min_reviews` … レビュー件数での絞り込み（「4. カテゴリの設定」）。

## 6. 紹介文CSV（ジャンル・女優・メーカー）

検索から入ってくるページ（ジャンル・女優）に、独自の文章を置くための仕組みです。

### CSV の規則
- 1行目は見出し。名前の列は、ジャンル=`ジャンル名` / 女優=`女優名` / メーカー=`メーカー名`。
- `説明` 列 = 紹介文の導入（最初の段落）。
- `作品数` 列 = 使わない（サイトが自動で件数を出す）。`--top` の並べ替えにだけ使える。
- それ以外の列は `【列名】値` の行になる。列を足すだけで項目が増える（列名は12文字まで）。
- 文字コードは UTF-8（BOM付き可）か Shift_JIS（Excelの既定）。自動判定。
- 名前は**サイトに表示されている名前と完全に一致**させる（例: `河北彩花（河北彩伽）`）。一致しない行は「見つからなかった」と報告される。
- 説明も【ラベル】も空の行は、登録されずに「空欄」として数えられる。

### 実行（GitHub Actions）
Actions → **紹介文のCSV取り込み** → Run workflow。

| 入力 | 意味 |
|---|---|
| `file` | CSV のパス（既定 `content/genre_list.csv`。女優は `content/actress_list.csv`） |
| `type` | `genre` / `actress` / `maker` |
| `dry_run` | **最初は true**。照合結果だけ確認し、書き込まない |
| `top` | 「作品数」の多い上位N行だけ登録（空=全行）。例: `20` |
| `overwrite` | 記入済みの紹介文も上書きするか（通常 false） |

### おすすめの進め方
1. ジャンル: `type=genre` / `top=20` / `dry_run=true` で確認 → 問題なければ `dry_run=false`。
2. 女優: `content/actress_list.csv` の空欄を**実際に作品を見て**書く（説明・魅力・おすすめの人・入口作品）→ `type=actress` / `dry_run=true` → 本番。
   人気女優の10名分が入っています。増やすときは行を足してください。

## 8. サイト側（PHP）の変更 — v1.11.0 で実装済み

| # | 変更 | 内容 |
|---|---|---|
| 1 | ヘッダー | 主要5項目（最安値 / セール / 高評価 / ジャンル / 女優）＋右側に「検索」「後で見る（保存件数つき）」。いま見ているページは下線で強調（ジャンル・女優の配下のページでも）。急上昇・新着・人気・メーカーなどはフッターへ。NTR・ハード系・素人のタブはヘッダーから外し、トップの「特集」行とフッターから入れる |
| 1b | フッター | 見出しつきの5グループ（安く買う / 作品を選ぶ / 探す / 特集 / サイト情報）。**ヘッダーにある項目は自動で省く**ので、同じリンクが重複しない。項目の定義は `av_hub_header_items()` と `av_hub_footer_groups()` の2か所だけ |
| 2 | トップの再構成 | 今日の最安値（ヒーロー）→ 高評価 → もうすぐ終了のセール → 急上昇 → 新着。機能リンクは「予算で選ぶ」「今が買い時」「埋もれた高評価」の3つだけ。人気ランキング・注目・値下がり中のセクションはトップから外した（各ページは残る） |
| 3 | 重複をなくす | トップ全体で同じ作品は1回だけ。トップの急上昇は「前回より順位を上げた作品」だけ（新規ランクインは `/trend/` に残る） |
| 4 | カードの見た目 | **画像には何も重ねない。** 上から「価格（現在価格を大きく・通常価格・割引率）→ 最安値 / セール終了までの時間 / ¥◯お得 / 過去最安まであと¥◯ → タイトル（2行まで）→ 順位タグ（人気◯位・↑・NEW IN・NEW）→ 女優・日付 → ★評価・スコア・件数少 → 購入ボタン（全幅）＋サンプル・後で見る」の順。価格の記録開始日は、トップの帯・ヒーロー・運営情報に表示 |
| 5 | 素人の扱い | トップ・新着・急上昇・注目・**新着RSS**から素人を除外。素人タブはレビュー3件以上の作品だけ |
| 6 | RSS（`/av/feed/sale/` `new/` `ending/`） | タイトルに価格・最安値・残り時間（例: `【¥350・最安値・あと2日】`）。本文（`content:encoded`）に、価格・通常価格・割引・お得額・過去最安との差・★評価とスコア・サイトの詳細リンク・FANZA購入リンク・PR表記。画像は既定で入れない（RSSリーダーでは年齢確認が効かないため） |
| 7 | RSSの案内ページ（`/av/feeds/`） | **ブラウザでRSSのURLを開くと、この案内ページへ転送**（購読URLのコピー、Feedlyで購読、届く内容の例）。RSSリーダーには従来どおりXMLを返す。フッターのRSSリンクはこのページ1本に統一 |

### 置き換え手順
1. 現在の `av_hub_mu_plugin.php`（または Code Snippets の中身）を**バックアップ**する。
2. `wp/av_hub_mu_plugin.php` で置き換える。DBの変更はなく、置き換えるだけで反映される。
3. キャッシュ系プラグインを使っていれば、キャッシュを削除する（トップの帯は最大10分、価格の記録開始日は最大1時間キャッシュされる）。
4. トップ、`/av/new/`、`/av/amateur/`、ヘッダーとフッターを確認する。

### 設定（`wp-config.php` に `define` を書くか、ファイル先頭の既定値を編集）
| 定数 | 既定 | 意味 |
|---|---|---|
| `AV_HUB_NAV_CATS` | `''` | ヘッダーに出すカテゴリのタブ（slugをカンマ区切り）。NTRだけ戻すなら `'ntr'`。戻したタブは、フッターの「特集」から自動で省かれる |
| `AV_HUB_GENERAL_EXCLUDE_CATS` | `'amateur'` | トップ・新着・急上昇・注目から外すカテゴリ。外さないなら `''` |
| `AV_HUB_HERO_N` | `6` | 「今日の最安値」に並べる作品数（3〜12） |
| `AV_HUB_FEED_IMAGES` | `false` | `true` にすると、RSSに作品画像（本文の画像と enclosure）を入れる |
| `AV_HUB_CATS` の `min_reviews` | amateur=3 | そのカテゴリのページに載せるレビュー件数の下限 |

`AV_HUB_CATS` を `wp-config.php` で定義している場合は、そちらにも `'min_reviews' => 3` を足してください（既定値は上書きされます）。

### RSSの表示について
- ブラウザは、2026年11月17日（Chrome 158）にXSLTのサポートを終了します。RSSをブラウザで見やすくする従来の方法（XSLT）は使えなくなるため、**人向けのHTMLページと、機械向けのXMLを分ける**方式にしました。
- 判定は、リクエストの `Accept` の先頭が `text/html` かどうかです（ブラウザは該当、RSSリーダーは通常該当しない）。`?format=xml` を付ければ、ブラウザでもXMLの中身を確認できます。`?format=html` は常に案内ページです。
- ページキャッシュに混ざらないよう、`DONOTCACHEPAGE` と `Vary: Accept` を出しています。CDN（Cloudflare等）を前に置いている場合は、`/av/feed/` 以下を「キャッシュしない」に設定してください。

### 知っておくこと
- 除外・非表示は表示の制御で、データは消していません。素人の低レビュー作品は、ジャンルページ（`/av/genre/素人/`）、検索、作品詳細には残ります。
- 「過去最安」は、価格の記録を始めた日以降のものです。価格が一度も動いていない作品には出しません。
- トップの「今日の最安値」は、価格の記録がまだ無いうちは「値下がり中（定価1,500円以上）」に切り替わります。

## 9. 困ったとき

| 症状 | 確認すること |
|---|---|
| 同期が 401 / 403 | `--mode check`（Actionsなら `mode=check`）。原因（認証ヘッダーが落ちている / ユーザー名違い / パスワード違い 等）と対処が出る |
| RSSのURLをブラウザで開くと案内ページに移る | 仕様です。中身のXMLを見たいときは、URLの末尾に `?format=xml` を付けてください |
| `サイト側にカテゴリ「xxx」がありません` | サイトの AVハブ が古い、または `AV_HUB_CATS` に `slug` が未登録。`categories.json` と揃える |
| `ジャンル名「…」のIDを特定できません` | `mode=cats` で候補を確認し、`genre_name` を直す |
| 素人が0件になった | `mode=cats` の「`min_reviews` を満たす作品」を確認。0件なら基準を下げるか 0 にする |
| 「急上昇」が空 | ランキングの履歴がまだ1日分しかない。2日目から出る |
| Bluesky が投稿されない | 急上昇・値下がりのデータが足りない日は投稿しない仕様。`dry_run` のログで理由を確認 |
| Actions が `ファイルがありません` | `.py` と `requirements.txt` がリポジトリの**直下**にあるか |
