# AVハブ（FANZA動画 一覧・ランキング・急上昇サイト）

WordPress（ConoHa WING）に **/av/** 以下の一覧サイトを作り、GitHub Actions が毎日 FANZA のデータを送り込む構成です。

```
GitHub Actions ──(DMM API取得 → 年齢フィルター)──▶ WordPress REST ──▶ 専用テーブル
                                                      │
Code Snippets の PHP ◀────────────────────────────────┘
  /av/ 新着・人気・急上昇・注目・セール・ジャンル/女優/メーカー・作品詳細・検索・後で見る
```

## セットアップ

### 1. WordPress 側
1. 設定 → 一般 → **タイムゾーンを「東京」** にする（日付・ランキングの切り替えがJSTになります）。
2. 設定 → パーマリンク → 「投稿名」など、`?p=123` 以外を選ぶ。
3. Code Snippets で新規スニペット → `wp/av_hub_snippet.php` の中身を貼り付け（**先頭に `<?php` は付けない**）→ 実行場所「どこでも実行」→ 保存して有効化。
4. `https://あなたのドメイン/av/` を開く（作品が無いので空のページが出ればOK）。
5. ユーザー → プロフィール → **アプリケーションパスワード** を作成（名前は何でも可）。管理者ユーザーで作ること。

### 2. GitHub 側
1. このフォルダを新しいリポジトリ（Private推奨）に置く。`.github/workflows/av_sync.yml` がリポジトリ直下の `.github` に入っていること。
2. Settings → Secrets and variables → Actions → Secrets に登録:
   `DMM_API_ID` / `DMM_AFFILIATE_ID` / `WP_URL`（例 `https://adult-navi21.com`、末尾スラッシュ無し）/ `WP_USERNAME` / `WP_APP_PASSWORD`
3. Actions → 「AVハブ同期」→ Run workflow
   - まず **dry_run = true**（取得とフィルターだけ確認。WPには送りません）
   - 問題なければ **mode = backfill**（初回の大量取り込み。人気順2000件＋直近90日の新着）
   - 以降は毎日自動（05:00 / 17:00 JST）。ランキング推移は**毎日たまっていく**ので、急上昇は2日目から表示されます。

### 3. 公開前にやること
- WordPress管理画面 → **AVハブ**: 人気上位の作品に「実際に見た感想」を2〜3行、主要なジャンル・女優に紹介文を書く。
  メモのある作品だけが検索に出る設定です（`AV_HUB_DETAIL_INDEX`）。
- Search Console に `https://あなたのドメイン/av-sitemap.xml` を送信。
- `age_filter.py` の除外パターンを、実データを見ながら**追加**していく（削除はしない）。運用中は GitHub の Variables `EXTRA_EXCLUDE`（カンマ区切りの正規表現）でも追加できます。

## 設定値（スニペット先頭の define）
| 定数 | 既定 | 意味 |
|---|---|---|
| `AV_HUB_PER_PAGE` | 30 | 1ページの作品数 |
| `AV_HUB_MIN_INDEX_ITEMS` | 8 | この件数未満のジャンル/女優ページは noindex |
| `AV_HUB_DETAIL_INDEX` | `note` | 作品詳細を検索に出す条件（note=メモあり / all / none） |

## 検索に出す・出さないの方針
- 出す: トップ、新着/人気/急上昇/セール、ジャンル・女優・メーカー（8作品以上）、メモを書いた作品詳細
- 出さない: 検索結果、2ページ目以降、メモの無い作品詳細、後で見る（noindex。検索結果・並び替えはrobots.txtでもクロール禁止）
- 並び替え・表示件数違いのURLは canonical で1つにまとめる

## 動作の目安
- 2万作品規模でも、一覧・検索は 0.1 秒前後で表示（テスト環境）。
- 「注目」タブは、当サイトの閲覧・クリックが一定数たまると自動で出現します。
- 「後で見る」「最近見た作品」は閲覧者のブラウザ内にのみ保存されます。

## 注意
- DMMアフィリエイトの規約（画像・サンプル動画の利用条件、表記義務）を必ず確認してください。
- すべてのページにPR表記を出しています。外さないでください。
- このフォルダの `age_filter.py` は、元の `age_safety_filter.py` の代わりに使います（元のリストは実質1件しか無かったため）。
